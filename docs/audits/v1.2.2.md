## Approved Scope

Version 1.2.2 publishes the reviewed Fira Code guide redesign. Canonical
fenced code uses the pinned upstream Fira Code 6.2 Regular face at 9.1/11.5 pt
with required, common, contextual, discretionary, historic, and TeX ligatures
disabled. The permanent pipeline retains the locked Regular/Bold font and OFL
evidence, but the release PDF embeds Bold only when content actually uses it.

The final promotion changes only release metadata, tests, release-facing
documentation, and the independent-release accessibility evidence boundary.

VPN, HPC login, scheduler query, job, allocation, or live-site mutation is
required.

## Accessibility Decision

The independent GitHub release uses the repository's explicit tracked
deferral path. Real screen-reader/viewer interoperability, keyboard-only
navigation, reflow, and a separate 200-percent viewer-zoom or magnification
session are recorded as **not tested**, not as passes. The available Windows
Narrator, Edge, Foxit, and UI Automation tools were identified, but no human
session was fabricated from a headless shell. The completed 200-DPI raster
comparison is visual regression evidence and is not mislabeled as viewer-zoom
or magnification testing.

Publication still requires the exact final PDF to pass every machine,
reproducibility, structure, extraction, OCR, font, PDF/UA-2, and rendered-page
visual gate. Any failure found by a performed review remains blocking. The
release and documentation make no WCAG 2.1 AA, universal assistive-technology,
disability-user-testing, institutional-endorsement, or UTC-accessibility-
approval claim. Institution-hosted or officially endorsed publication remains
subject to the institution's own process.
